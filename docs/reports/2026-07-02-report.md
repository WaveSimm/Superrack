## 오늘 완료 (모두 실기 동작 확인)

### Phase 2 — 채널별 Dry 멀티트랙 녹음 ✅ 실기 검증
- `MultitrackRecorder`: `ThreadedWriter` 락프리 FIFO + 공유 `TimeSliceThread`, 채널별 32f 모노 WAV
- 오디오 콜백 말미 Dry tap(`inputChannelData` = 스트립 처리 전 원음)
- **실기 검증**(UR22mkII 96kHz 루프백): 포맷/동기(샘플수 완전일치)/SR-드라이버추종 PASS. ch01(dry) vs ch02(Out1→In2) 상관 r=0.972. Q3 노치 3kHz가 ch02(wet)에만 → dry tap이 플러그인 앞임 증명

### 멀티채널 화면 재설계
- 세로 스크롤 랙 로우 + 얇은 툴바 + 별도 설정 창(`SettingsWindow`)
- 셰브런(화살표) 플러그인 카드(5각 라운딩) + 이름 실측폭 동적 칩
- 굵은 버튼 라벨, 28px 컴팩트 행, 짝/홀 교차 배경
- **채널 수 동적화**: strips 32개 사전할당(주소 안정), GUI는 활성 채널 수만큼 행 표시

### P3 견고화
- **채널별 출력 게인**(ChannelStrip atomic, 행별 LinearBar, wet만/Dry녹음 무관)
- **세션 저장/로드**(JSON: device/channels/strips[plugins{path,bypass,base64},outGainDb,name]) — 자동복원+수동 `.superrack`
- **xrun/CPU 표면화**(툴바 우측)
- **채널 이름** 편집 필드(세션 저장)

### 통합 타임라인 녹음/재생 (신규 스코프)
- 트랜스포트 상태기계(Stopped/Recording/Playing), `TimelinePlayer`(스템 동기 재생, BufferingAudioSource read-ahead)
- 트랜스포트 행: ⏮ ⏭ ● ▶ ■ + 시간 + 진행바 시크 + "재생 시 플러그인 통과" 토글
- **펀치인**: 정지 위치(playhead)부터 이어 녹음, 통합 playhead로 정지 후 그 자리 유지
- 재생 중 라이브 입력 뮤트

### 테이크 모델 (3파일 계층)
- **설정**(audio-settings.xml) / **세션**(session.json·.superrack) / **테이크**(takes/&lt;id&gt;/)
- 테이크 = `chNN_dry.wav` + `timeline.json`(환경·length·history·updatedAt) + `session.json` 스냅샷 = 자기완결 프로젝트
- 폴더 난립 해결: 녹음/펀치는 현재 테이크 파일 제자리 갱신(`.rectmp` 스크래치 + 임시파일 스왑 커밋)
- 새 테이크 버튼 / 테이크 셀렉터(마지막 녹음시각·ch·SR·길이) / 삭제(확인)
- 테이크 로드 시 세션 자동복원 + 환경 SR 불일치 경고

## 잡은 버그
- 세션 자동저장이 장치 없을 때 빈 데이터로 덮어쓰던 문제 → `getCurrentAudioDevice()==null`이면 저장 생략
- 녹음 정지 시 playhead가 0으로 리셋 → 통합 playhead 도입, 정지 위치 유지 + 이어 녹음
- 펀치인으로 짧아진 테이크 길이 미반영(`jmax`) → `finalLen` 사용(펀치는 끝까지 덮어쓰기)
