# 레이턴시 측정 — Yamaha Steinberg UR22mkII

> 측정일: 2026-06-29 · 도구: Superrack 내장 루프백 테스터(Out1→In2 임펄스)
> 장치: Yamaha Steinberg USB ASIO (UR22mkII), 48000 Hz

## 측정값

| 버퍼 | 버퍼 지연 | 실측 RTL | 드라이버 보고 | 차이(컨버터) |
|------|-----------|----------|---------------|--------------|
| 64 samples   | 1.3 ms  | 904 smp / **18.83 ms** | 780 smp / 16.25 ms | 124 smp / **2.58 ms** |
| 1024 samples | 21.3 ms | 3399 smp / **70.81 ms** | 3276 smp / 68.25 ms | 123 smp / **2.56 ms** |

## 해석

- **실측 RTL = 외부 믹서 인서트 왕복 지연**: 믹서 출력 → ADC+입력버퍼 → Superrack(VST3) → 출력버퍼+DAC → 믹서 입력. 루프백(출력→입력)과 동일 합산이므로 실사용 인서트 왕복과 같다.
- **고정 컨버터 지연 ≈ 123~124 smp (≈ 2.56 ms)**: 버퍼를 16배(64→1024) 키워도 실측−보고 차이가 거의 불변 → DAC+ADC 아날로그 변환 지연. 드라이버 보고값(버퍼 기반)에는 빠져 있고 루프백 실측만 포착.
- **버퍼 의존 지연**: 나머지(드라이버 보고분)는 USB 스트리밍 버퍼링으로 버퍼 크기에 비례.
- **측정 제외 항목**: 테스트 중 VST3 체인 우회 → 실측 RTL에 **플러그인 자체 지연 미포함**. 실제 인서트 총지연 = 실측 RTL + 플러그인 PDC(예: linear-phase EQ 는 수 ms~수십 ms 추가, zero-latency 모드 ≈ 0).

## 실용 함의
- UR22mkII(USB 클래스)는 64샘플에서도 왕복 ~18.8 ms → 라이브 인서트로는 다소 큼.
- 저지연이 중요하면 더 낮은 레이턴시 인터페이스(TB/PCIe)와 작은 버퍼, 라이브에선 고지연 플러그인 회피.
- 측정 방법론은 설계서 §5.2 / §7 참조.
