# Superrack 사용법

ASIO 오디오 인터페이스의 입력 채널마다 VST3 플러그인 체인을 걸어 같은 번호 출력으로
내보내는 라이브 인서트 프로세서입니다. 동시에 원음(Dry)을 채널별로 녹음해두고
나중에 재생하며 플러그인 세팅을 다듬을 수 있습니다.

---

## 1. 시작하기

1. `Superrack.exe` (또는 `Superrack Beta.exe`) 실행
2. 상단 **⚙ 설정** 클릭 → 오디오 장치 목록에서 **ASIO** 드라이버 선택
3. 샘플레이트·버퍼 크기 설정 (버퍼가 작을수록 지연이 짧지만 CPU 부담↑)
4. 입력/출력 채널 수 지정 (2채널부터 시작 권장, 최대 32)

> 설정은 자동 저장되어 다음 실행에 그대로 복원됩니다. 장치가 없으면 소리·미터가 동작하지 않습니다.

---

## 2. 채널에 플러그인 걸기

세로로 늘어선 채널 칸(랙)에서 채널마다:

- **＋ 플러그인** — VST3 추가 (위→아래 순서대로 직렬 연결)
- **바이패스** — 켜면 그 플러그인만 통과(원음), 끄면 적용
- **플러그인 이름 클릭** — 네이티브 편집 창 열기
- **출력 게인** — 채널 wet 출력 음량 (−60 ~ +12 dB)

입력 신호가 들어오면 왼쪽 **입력 미터**가 반응합니다. 플러그인은 실시간으로 추가·제거해도
소리가 끊기지 않습니다.

> 플러그인이 표준 위치(`C:\Program Files\Common Files\VST3`)에 없으면
> ⚙ 설정 → **VST3 추가 검색 경로**에 폴더를 등록하세요.

---

## 3. 녹음과 재생 (트랜스포트)

상단 트랜스포트 줄:

| 버튼 | 기능 |
|---|---|
| ● | **녹음** — 현재 테이크에 원음(Dry) 캡처. 재생 위치부터 이어 녹음(펀치인) |
| ▶ | **재생** — 녹음된 원음을 재생. "재생 시 플러그인 통과" 켜면 체인 거쳐 들림 |
| ■ | **정지** |
| ⏮ / 진행바 | 처음으로 / 드래그해서 위치 이동(시크) |

- 녹음되는 것은 **플러그인 걸기 전 원음**입니다. 재생하며 플러그인을 바꿔가며 세팅을 잡으세요.
- 진행바 아래 **주황/회색 밴드** = 녹음한 구간 표시 (주황 = 방금 녹음한 부분).

---

## 4. 테이크 (녹음 프로젝트)

트랜스포트 아래 테이크 줄에서 녹음물을 관리합니다.

- **테이크 선택 콤보** — 고르면 그때의 플러그인 세팅까지 자동 복원. 최근 녹음이 맨 위
- **＋ 새 테이크** — 빈 녹음 프로젝트 시작 (기존은 보존)
- **삭제** — 선택한 테이크 영구 삭제
- **⟲ 녹음 복구 / ⟳ 복구 취소** — **방금 한 녹음이 마음에 안 들면 직전 상태로 되돌리기** (다시 누르면 앞으로)

> 실수로 덮어 녹음해도 "⟲ 녹음 복구"로 직전 녹음을 되살릴 수 있습니다 (직전 1회).

---

## 5. 앱 설정 (⚙ 설정 하단)

- **녹음/테이크 저장 위치** — 녹음 파일이 저장될 폴더. **로컬 드라이브 권장**
  (OneDrive 등 클라우드 동기화 폴더는 녹음 중 끊김을 유발할 수 있음)
- **VST3 추가 검색 경로** — 표준 위치 외 플러그인 폴더 (회색 = 기본, 아래에 추가)
- **병렬 DSP 워커 수** — 보통 "자동". 채널이 많고 CPU 여유가 있으면 자동이 최적

---

## 6. 진단 도구 (상단 툴바)

- **RT 레이턴시** — Out1→In2 를 케이블로 연결한 뒤 실제 왕복 지연 측정
- **CPU 프로파일** — 현재 플러그인 체인으로 몇 채널까지 안정적인지 자동 측정 → 리포트 저장

---

## 7. 자주 겪는 문제

| 증상 | 확인 |
|---|---|
| 소리가 안 남 | ⚙ 설정에서 ASIO 장치가 선택됐는지, 입출력 채널이 잡혔는지 |
| 소리가 끊김(xrun) | 버퍼 크기를 키우거나 무거운 플러그인 수를 줄이기 |
| "재생 언더런" 표시 | 저장 위치를 빠른 로컬 드라이브로 변경 |
| 플러그인이 안 열림 | VST3 추가 검색 경로 등록, 유료 플러그인은 해당 PC에서 인증 |
| 다른 PC에서 세팅 복원 시 일부 플러그인 빠짐 | 그 PC에 같은 플러그인 설치 필요 (경로가 달라도 자동으로 찾음) |
