### 확정 1 — 병렬 스피드업 3.0× (완전 통제 A/B)
Run 5 vs 6: 동일 체인·동일 설정에서 avg 비 8ch 88.2→29.2%, 16ch 174.9→59.0% = **3.0×** (5레인 이론 4.8× 대비 효율 62%). 한계 4ch→16ch. 어제 추정치(2.8×)가 통제 실험으로 확정됨.

### 확정 2 — ms급 peak 스파이크는 **병렬 모드에서만 발생**
- 직렬: 과부하 상태에서도 peak/avg ≈ 1.1~1.3 (xrun 은 avg 포화 때문). 96k/96 2ch 직렬은 peak 74.7%로 클린 — Run 3(병렬 동일 조건)의 1336% 스파이크가 재현 안 됨.
- 병렬: 96k/96 에서 저채널부터(Run 3), 96k/512 에서 24ch+ 부터(Run 4·5), 2단 체인 16ch 부터(Run 8) 300~1400% 스파이크.
- **결론: 워커 풀 경로의 간헐 스톨** (웨이크 지연 또는 잡 클레임 후 워커 프리엠션 — 오디오 스레드가 조인에서 대기). 플러그인·드라이버는 무혐의. 13ms 급 스톨은 spin→이벤트 2ms 타임아웃 폴백으로도 설명이 안 되므로 조사 필요 → BACKLOG A3.

### A2 잠정 결론
